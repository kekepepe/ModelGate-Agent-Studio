# Agent Registry UI 设计规范

> 所属产品：ModelGate Agent Studio
>
> 关联文档：agent-workspace-ui-spec.md（共享设计系统）
>
> 文档定位：Agent Registry 前端 UI 设计规范，覆盖 Agent Station 列表、配置表单、模板创建、启用禁用交互。不包含代码实现。

---

## 1. Design Read

**Reading this as:** B2B developer-tool configuration surface for multi-model power users, with a structured / role-centric / station-metaphor language, leaning toward the same warm-neutral system as Agent Workspace (Stone surface + muted functional accents + high information density).

**核心隐喻：** Agent 是「工位（Station）」，不是「模型 API Key」。工位有固定职责、可更换设备（模型）、可控工具权限、可配置交接策略。整个页面应传递「组织一个团队协作办公室」的感知，而不是「管理一组 API 凭证」。

---

## 2. Three Dials

| Dial                 | Value | Rationale                                                                                                       |
| -------------------- | ----- | --------------------------------------------------------------------------------------------------------------- |
| `DESIGN_VARIANCE`  | 5     | Tool surface; symmetrical list layout with asymmetric detail/config panel. Role icons add mild visual variance. |
| `MOTION_INTENSITY` | 3     | Functional only: form transitions, status changes, modal open/close, switch feedback.                           |
| `VISUAL_DENSITY`   | 7     | Configuration page; dense form fields, grouped permissions, model selectors.                                    |

---

## 3. 信息架构（4 层）

Agent Registry 需要让用户理解「有哪些工位、每个工位配置什么、工位之间的关系」。信息按 4 层组织：

| 层级                     | 作用                                           | 承载位置                           |
| ------------------------ | ---------------------------------------------- | ---------------------------------- |
| **L1 — 全局视角** | 查看所有工位，快速筛选和定位                   | AgentList 页面                     |
| **L2 — 工位摘要** | 一眼看到工位角色、状态、绑定模型、Handoff 能力 | AgentList 行/卡片                  |
| **L3 — 工位配置** | 编辑工位的完整配置：模型、工具、Prompt、限制   | AgentConfigForm（模态框/侧板）     |
| **L4 — 工位统计** | 查看工位历史表现（任务数、交接数、成功率）     | AgentStatsPanel（P1，抽屉/标签页） |

**布局规则：**

- 页面最大宽度 `max-w-[1400px] mx-auto`。
- 列表采用紧凑行（row）形式，非卡片网格。管理型配置页面中，行比卡片更高效。
- 每行高度 64px，行与行之间用 `border-b` 分隔。
- Hover 行时背景变为 `bg-stone-50`，过渡 150ms。
- 禁用状态的 Agent 行：整体透明度降至 60%，文字颜色降为 `text-stone-400`，背景为 `bg-stone-50/50`。
- 点击整行或 [编辑] 按钮打开配置表单。

**列宽分配（桌面端 ≥1280px）：**

| 列              | 宽度                  | 说明                                                        |
| --------------- | --------------------- | ----------------------------------------------------------- |
| 角色图标 + 名称 | flex-1, min-w-[200px] | 左对齐，图标 32px + 名称 14px 字重 500 + 描述 12px 次要文字 |
| 角色标签        | 120px                 | 居中，RoleTag 样式                                          |
| 状态            | 100px                 | 居中，StatusIndicator                                       |

| 启用开关        | 64px                  | 固定，Switch 组件                                           |
| 操作            | 100px                 | 固定，[编辑] 下拉菜单                                       |

**移动端（<768px）：**

- 表格退化为卡片列表
- 每张卡片包含：角色图标 + 名称、RoleTag、StatusIndicator、模型名、Handoff 状态、启用 Switch
- 点击卡片进入独立配置页（非模态框，因屏幕宽度不足）

## 5. 组件规范

### 5.1 RoleTag（角色标签）

用于列表和表单中展示 Agent 的角色类型。

**形态：**

### 5.2 StatusIndicator（状态指示灯）

用于列表中展示 Agent 的当前运行状态。

**形态：**

- 左侧 8px 圆点 + 右侧状态文本
- 圆点与文本间距 6px
- 整体高度 20px

**颜色映射：**

| 状态         | 圆点                                 | 文字                     | 说明                 |
| ------------ | ------------------------------------ | ------------------------ | -------------------- |
| `idle`     | 实心 `#22c55e` (绿-500)            | `#15803d` (绿-700)     | 空闲，可接收任务     |
| `running`  | 实心 `#3b82f6` (蓝-500) + 微弱脉动 | `#1d4ed8` (蓝-700)     | 执行中，唯一脉动动画 |
| `handoff`  | 实心 `#8b7ec8` (薰衣草)            | `#5b4ba4` (薰衣草-800) | 交接中               |
| `error`    | 实心 `#ef4444` (红-500)            | `#b91c1c` (红-700)     | 错误                 |
| `disabled` | 实心 `#a8a29e` (暖灰-400)          | `#78716c` (暖灰-500)   | 禁用                 |
| `blocked`  | 实心 `#f59e0b` (琥珀-500)          | `#b45309` (琥珀-700)   | 阻塞                 |

**running 脉动动画：**

- box-shadow 脉动：`0 0 0 0 rgba(59, 130, 246, 0.4) → 0 0 0 4px rgba(59, 130, 246, 0)`
- 周期 2s，ease-out，infinite
- 仅圆点区域，不影响布局

### 5.3 ModelBindingSelector（模型绑定选择器）

用于表单中的默认模型和备用模型选择，核心表达「主设备 + 备用设备」的关系。

**默认模型选择：**

- 单选下拉框，展示所有已启用模型
- 每个选项展示：模型名（14px 字重 500）+ 提供商（12px `text-stone-400`）+ 能力标签（如 code、planning）
- 选中后在下拉框外展示模型卡片：白色面板 + 左侧色条（不同提供商不同颜色）+ 模型名 + 提供商

**备用模型选择：**

- 多选复选框列表，按提供商分组
- 每个复选框旁展示模型名 + 能力标签
- 已被选为默认模型的选项自动禁用并标注「默认模型」
- 选中备用模型后，在下方以水平 chip 列表展示已选备用模型
- chip 可点击移除（× 图标）

**模型关系可视化（表单顶部）：**

```
+---------------+      +---------------+      +---------------+
| Claude 3 Opus |  →   | GPT-4 Turbo   |  →   | DeepSeek Chat |
|   (默认)       |      |   (备用 1)     |      |   (备用 2)     |
+---------------+      +---------------+      +---------------+
```

- 三个模型卡片水平排列，中间用箭头连接
- 默认模型卡片边框为 `stone-400`，备用模型卡片边框为 `stone-200`
- 箭头颜色 `stone-300`，表示「失败时自动切换方向」

### 5.4 ToolPermissionSelector（工具权限选择器）

用于表单中选择 Agent 允许使用的工具，按类别分组展示。

**形态：**

- 按类别分组：文件操作、终端、网络、代码、其他
- 每组有组标题：12px 字重 600，`text-stone-500`
- 组内工具用复选框列表展示
- 每个工具项：复选框 + 工具名（14px 字重 500）+ 描述（12px `text-stone-400`）

**高风险工具标识：**

- `file_delete`、`terminal_execute` 等高风险工具旁有警告图标（16px，琥珀色）
- 选中高风险工具时，弹出确认对话框：
  - 标题：「启用高风险工具」
  - 内容：「terminal_execute 允许 Agent 执行系统命令，可能导致数据丢失。请确认您了解风险。」
  - 按钮：[取消] [确认启用]
- 已启用的高风险工具在列表中以琥珀色背景高亮

---

### 5.5 HandoffToggle（Handoff 开关组）

用于表单中控制 Agent 是否允许 Handoff 及设置阈值。

**形态：**

- 顶部 Switch 组件控制 `allow_handoff`
- Switch ON 时，下方展开阈值输入框
- Switch OFF 时，阈值输入框隐藏（高度动画 250ms）
- 阈值输入框：数字输入 + 单位「tokens」+ 范围提示「建议 1000-100000」

**角色默认建议：**

- Planner、Summarizer、Supervisor 默认建议关闭 Handoff
- 当用户为这些角色开启 Handoff 时，显示弱提示：「该角色通常不需要交接，确定开启？」

---

### 5.6 AgentStationRow（列表行）

用于列表页展示单个 Agent Station。

**规则：**

- 整行高度 64px，垂直居中
- 左侧 32px 角色图标（圆角 8px，背景为角色对应色 10% 透明度）
- 名称：14px 字重 500，`text-stone-800`
- 描述：12px `text-stone-400`，单行截断
- RoleTag 位于名称右侧或独立列
- StatusIndicator 位于状态列
- 模型名：12px 字重 500 + 提供商标签（10px，`text-stone-400`，圆角 4px 背景 `stone-100`）
- Handoff 状态：ON 显示绿色小 pill，OFF 显示灰色小 pill
- 启用 Switch：标准 Switch 组件，切换时有 200ms 过渡
- 操作按钮：[编辑] 文本按钮，`text-stone-500`，hover `text-stone-800`
- 整行 hover：`bg-stone-50`
- 禁用状态：整体 `opacity-60`，Switch 禁用，[编辑] 按钮保留（可查看配置但不可修改部分字段）

## 6. 交互流程

### 6.1 创建 Agent 流程

```
1. 用户点击 [创建 Agent] 按钮
2. 弹出模板选择模态框（Step 1）
   - 展示 6 个 TemplateCard + 1 个「自定义」卡片
   - 用户点击选择模板或「自定义」
3. 进入配置表单模态框（Step 2）
   - 若选了模板，表单预填充对应字段
   - 若选「自定义」，表单全部为空
4. 用户填写/修改配置
   - 实时校验：名称非空、默认模型已选
   - 高风险工具选中时弹出确认
5. 用户点击 [保存]
   - 前端校验通过后调用 POST /agents
   - 显示「创建中」loading 状态
   - 成功：关闭模态框，列表刷新，显示 Toast「Agent 创建成功」
   - 失败：表单顶部显示错误横幅，不关闭模态框
6. 新 Agent 出现在列表顶部（带高亮动画 2s）
```

**创建入口规则：**

- 页面顶部 [创建 Agent] 主按钮
- 空状态时中央显示 [创建第一个 Agent] 大按钮
- MVP-B 阶段 Workspace 中 Agent Station 区域增加 [+] 快捷入口

### 6.2 编辑 Agent 流程

```
1. 用户在列表中点击 [编辑] 或整行
2. 弹出配置表单模态框，字段预填充当前值
3. 表单顶部显示 Agent 当前状态
   - 若 status = running：显示警告横幅「该 Agent 正在执行任务，修改配置仅对新任务生效」
4. 用户修改配置
   - 修改 role 时：弹出确认「修改角色可能影响历史任务统计，是否继续？」
   - 修改 default_model_id 时：显示弱提示「修改后仅影响新任务」
   - 修改 handoff_enabled 为 false 时：显示弱提示「禁用后该 Agent 将无法触发 Handoff」
5. 用户点击 [保存]
   - 调用 PATCH /agents/:id
   - 成功：关闭模态框，列表对应行更新，Toast「配置已保存」
   - 失败：表单顶部显示错误横幅
```

**编辑约束 UI 表达：**

- running 状态的 Agent：允许编辑所有字段，但保存时 API 可能拒绝关键字段变更
- disabled 状态的 Agent：允许编辑，编辑后仍为 disabled，需手动启用

### 6.3 启用/禁用 Agent 流程

```
1. 用户在列表中找到目标 Agent
2. 点击该行的启用/禁用 Switch
3. 若 Agent 当前没有 running 任务：
   - Switch 直接切换
   - 调用 PATCH /agents/:id/status
   - 禁用后：行变灰，StatusIndicator 变为 disabled
   - Toast 显示「Agent 已禁用」/「Agent 已启用」
4. 若 Agent 当前有 running 任务且用户尝试禁用：
   - Switch 回弹到原状态
   - 弹出确认对话框：
     - 标题：「该 Agent 有进行中任务」
     - 内容：「Coder Agent 正在执行「实现登录模块」。禁用后该 Agent 不再接收新任务，但当前任务会继续执行。您也可以先 Handoff 该任务。」
     - 按钮：[取消] [强制禁用] [查看任务并 Handoff]
   - 用户选择 [强制禁用]：任务标记为 failed，Agent 禁用
   - 用户选择 [查看任务并 Handoff]：跳转 Workspace 对应 Task
   - 用户选择 [取消]：无操作
```

**Switch 组件规则：**

- 高度 24px，宽度 44px
- ON 状态：背景 `#166534` (鼠尾草-700)，圆点靠右
- OFF 状态：背景 `#d6d3d1` (暖灰-300)，圆点靠左
- 切换动画：圆点位置 200ms，`cubic-bezier(0.4, 0, 0.2, 1)`
- 禁用状态（控件本身禁用）：背景 `#e7e5e4` (暖灰-200)，圆点 `#a8a29e`

### 6.4 模板选择流程

```
1. 用户点击 [创建 Agent] 或 [从模板创建]
2. 弹出模板选择模态框
   - 标题：「选择 Agent 模板」
   - 内容：6 个 TemplateCard 网格（3 列）+ 1 个「自定义」卡片
   - 底部：[取消] 按钮
3. 用户点击某个 TemplateCard
   - 卡片有选中状态（边框高亮 + 勾选标记）
   - 底部出现 [下一步] 主按钮
4. 用户点击 [下一步]
   - 关闭模板选择模态框
   - 打开配置表单模态框，预填充模板数据
   - 表单顶部显示「基于 Coder 模板创建」标签，可点击「更换模板」回到上一步
5. 用户修改后保存
```

## 8. 失败与警告状态

### 8.1 表单校验错误

- 名称空：输入框边框变红，`#dc2626`，下方显示「Agent 名称不能为空」
- 默认模型未选：下拉框边框变红，下方显示「请选择默认模型」
- System Prompt 空：文本域边框变红
- 非法 role：下拉框边框变红
- 保存时 API 返回 400：表单顶部显示错误横幅，背景 `brickred-50`，文字 `brickred-800`，左侧 AlertTriangle 图标

### 8.2 运行中 Agent 编辑警告

- 表单顶部显示警告横幅：背景 `amber-50`，文字 `amber-800`，左侧 AlertTriangle 图标
- 文案：「该 Agent 正在执行任务，配置修改仅对新任务生效」

### 8.3 禁用冲突

- 弹出确认对话框（见 6.3 流程）
- 对话框中 [强制禁用] 按钮为红色次按钮
- [查看任务并 Handoff] 为蓝色次按钮

## 9. 交互动效

| 场景             | 动效                                                                                 | 时长  | 缓动                              |
| ---------------- | ------------------------------------------------------------------------------------ | ----- | --------------------------------- |
| 模态框打开       | 整体 `scale(0.96) → scale(1)` + `opacity 0 → 1`，背景遮罩 `opacity 0 → 0.3` | 250ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 模态框关闭       | 反向                                                                                 | 200ms | ease                              |
| 列表行 hover     | `bg-stone-50`                                                                      | 150ms | ease                              |
| 新 Agent 高亮    | 行背景 `bg-lavender-50 → bg-white`，过渡 2s                                       | 2s    | ease-out                          |
| Switch 切换      | 圆点位置 + 背景色                                                                    | 200ms | `cubic-bezier(0.4, 0, 0.2, 1)`  |
| Handoff 阈值展开 | 高度 `0 → auto` + `opacity 0 → 1`                                              | 250ms | ease                              |
| 模板卡片 hover   | 边框色变化 +`shadow-sm`                                                            | 200ms | ease                              |
| 模板卡片选中     | 边框 1px → 2px，勾选标记 `scale(0) → scale(1)`                                   | 200ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 保存 loading     | 按钮内显示 Spinner，按钮宽度不变                                                     | —    | —                                |
| Toast 出现       | 从顶部滑入 8px +`opacity 0 → 1`                                                   | 300ms | ease-out                          |
| 运行状态脉动     | box-shadow 扩散                                                                      | 2s    | ease-out, infinite                |

## 10. 响应式策略

| 断点              | 布局变化                                         |
| ----------------- | ------------------------------------------------ |
| `≥1280px`      | 完整列表 7 列，配置模态框 720px                  |
| `768px–1279px` | 隐藏描述列，Handoff 列缩小，模态框 90vw          |
| `<768px`        | 列表退化为卡片，配置表单变为独立页面或底部 Sheet |

**移动端配置表单：**

- 使用全屏底部 Sheet（从底部滑出，高度 90vh）
- 区块标题更大（14px）
- 工具权限每组占满宽度
- 底部固定保存/取消按钮栏
