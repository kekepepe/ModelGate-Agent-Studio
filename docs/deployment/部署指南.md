# ModelGate Agent Studio 部署指南

> 当前部署形态：FastAPI + SQLite + React 静态构建 + Nginx。

## Docker Compose 部署

```bash
git clone <repository-url> modelgate-agent-studio
cd modelgate-agent-studio
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
docker compose up -d --build
docker compose ps
```

访问 `http://<服务器地址>/`。前端 Nginx 将 `/api/v1` 代理到内部 `backend:8000`，无需公开后端端口。

查看日志与停止：

```bash
docker compose logs -f backend
docker compose logs -f frontend
docker compose down              # 保留 SQLite volume
# docker compose down -v         # 删除数据，谨慎使用
```

## 真实模型 Provider

当前支持 `mock` 与 `openai`（OpenAI-compatible）：

```bash
export MODEL_PROVIDER=openai
export OPENAI_BASE_URL=https://api.openai.com/v1
export OPENAI_API_KEY='replace-with-secret'
export OPENAI_TIMEOUT=60
docker compose up -d --build
```

不要把 API Key 写进 Dockerfile、前端 `VITE_*` 变量或 Git；生产环境请用 Docker secret、Vault 或云端 secret manager。

## 数据备份

SQLite 位于 `modelgate-data` volume 的 `/app/data/modelgate.db`。升级前先备份：

```bash
docker compose stop backend
mkdir -p backups
docker run --rm -v modelgate-agent-studio_modelgate-data:/data:ro \
  -v "$PWD/backups:/backup" alpine \
  sh -c 'cp /data/modelgate.db /backup/modelgate-$(date +%Y%m%d-%H%M%S).db'
docker compose start backend
```

## 生产上线门槛

当前项目可用于单机 MVP 验证；公网生产前必须完成：

1. `DEBUG=false`，并将 CORS 从本地 5173/5174 改为正式域名或保持同域代理。
2. HTTPS、限流、安全响应头和认证授权。
3. 备份/恢复演练；多副本或高并发时迁移至 PostgreSQL。
4. 真实 Provider 的错误分类、重试、超时、脱敏日志和密钥管理。
5. 按 [Migration 切换计划](../implementation/database-migration-cutover-plan.md) 接入版本化 migration；不要对既有库回放历史 `migrations/*.sql`。
