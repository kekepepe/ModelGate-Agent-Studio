## 质量限制

- 100-task DAG 已证明不溢出且状态切换稳定，但当前主视图重点展示当前 Task，而非同时可视化全部 100 个节点；对超大计划的全局图仍可改进。
- 前端产物包含约 1.66 MB 的 office PNG；不阻塞功能，但值得做图片压缩与响应式资源。
- 本机 `.venv` 是 Python 3.9.6；CI/Docker 目标固定 3.12.8。最终发布必须以 GitHub Python 3.12 workflow 与镜像 smoke 为准。
- RAG 当前报告使用 LocalHash；真实 embedding runner 会直接使用 `RealEmbeddingProviderAdapter` 并在 Provider 失败时失败，不允许降级伪通过，但尚无凭据执行。
