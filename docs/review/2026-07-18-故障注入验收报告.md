# ModelGate Agent Studio 故障注入验收报告

日期：2026-07-18  
结论：代码级故障恢复门禁通过；真实 Provider 和真实进程破坏性演练仍受外部环境限制。

## 覆盖矩阵

| 故障 | 证据 | 结果 |
|---|---|---|
| Provider 401 / 429 / 500 / timeout / context overflow | `test_openai_compatible_provider.py` 错误分类测试 | 统一映射，任务不误完成 |
| Streaming 中断 / 空内容 / 错误 JSON | Provider 流终止、空响应、非法响应测试 | 显式失败，可恢复或重试 |
| Tool call 格式错误 | Runtime V2 tool contract tests | 输入拒绝并审计 |
| 命令超时 / 非零退出 / Build 退出 | `test_fault_injection.py` | ToolCallRecord 为 failed，保存退出证据 |
| 文件并发修改 | checksum 乐观并发测试 | 原文件保留，返回 `concurrent_modification` |
| 磁盘不足 / 权限不足 | 注入 `OSError(28)` 与 `PermissionError` | 无 Artifact，错误可见 |
| Worktree 创建失败 | 非 Git Workspace 注入测试 | Task 进入 blocked，原因入日志 |
| Git merge conflict | `test_worktree_service.py` 真实临时仓库冲突 | 文件列表与 Git 输出保留，可进入 resolution |
| 数据库断连 / transaction rollback | SQLAlchemy `OperationalError` 注入 | 状态和事件共同回滚 |
| Verification 持久化 deadlock | commit 路径注入 | Task 为 failed，绝不 completed |
| 非法状态跳转 | `test_state_machine.py` | 拒绝并保持旧状态 |
| Scheduler 重启 / Worker 重复消费 | recovery lease 与 idempotency tests | 只恢复过期租约，不重复已验证任务 |
| Handoff / Replan 原子性 | handoff、replan rollback tests | 接收/版本切换失败时回滚 |
| Secret 出现在工具输入或异常 | redaction tests | 持久化记录为 `[REDACTED]`，执行仍用原值 |

## 验收原则

所有测试同时断言最终状态、可见错误和“不能误标 completed”。已验证副作用由 idempotency key、Artifact checksum 与状态租约保护。不可安全自动重放的操作保持 blocked 或等待人工确认。

## 尚未替代的真实演练

- 未使用真实 Provider 制造供应商侧 401/429/500、限流恢复与流中断；当前是协议级注入。
- 未对宿主机真实磁盘打满，也未强制杀死生产进程；当前使用确定性异常和重启状态夹具。
- 未对生产 PostgreSQL 制造真实 deadlock；当前在 Verification 持久化边界注入 `OperationalError`。

这些限制不会被计为真实环境通过项；必须在预生产环境的受控演练中补证。
