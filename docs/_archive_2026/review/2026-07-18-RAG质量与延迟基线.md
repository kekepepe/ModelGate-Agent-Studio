## 实现与口径

- 查询先在数据库中执行关键词 Top-N 候选召回，再对有限候选做 embedding decode、cosine 和 rerank，不再无界遍历全部 Chunk。
- LocalHash 是词法 Adapter。为避免哈希碰撞制造伪语义命中，结果必须有至少两个归一化关键词佐证，或具有精确文本/路径命中。
- Embedding Adapter、模型、版本、维度、稳定指纹和降级原因写入 Source/Chunk 元数据；模型指纹改变会触发重建。
- 私有 Source 与禁用 Source 都进入固定负向样本，当前召回率均为 0。

## 限制

这是一套小型、仓库内、确定性回归基线，不等同于真实业务语料上的语义检索质量。`RealEmbeddingProviderAdapter` 已通过注入式 HTTP 合约测试和故障降级测试，但当前环境没有 `PROVIDER_API_KEY` 与 `EMBEDDING_MODEL_NAME`，因此尚未形成真实 embedding Provider 的网络验收证据。Nightly 使用以下严格命令；该模式直接实例化真实 Adapter，网络失败时不会降级成 LocalHash 通过：

```bash
python backend/scripts/rag_eval.py --embedding-backend real \
  --output live-embedding-rag.json --enforce-thresholds
```
