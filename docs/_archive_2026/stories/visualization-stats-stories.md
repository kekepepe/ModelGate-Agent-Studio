# Visualization & Statistics User Stories

> 模块：P2-2 Visualization & Statistics
> 日期：2026-07-02

## US-VS-01 查看系统概览

**作为** 项目操作者，
**我想要** 在 Dashboard 顶部看到系统关键指标，
**以便** 快速判断当前运行状态。

### 验收标准

- 显示活跃目标数。
- 显示今日完成目标数。
- 显示今日 Token 总量。
- 显示今日模型调用次数。
- 显示今日工具调用次数。
- 显示今日 Handoff 次数。
- 无数据时显示 0，而不是空白或报错。

## US-VS-02 查看 Token 与调用趋势

**作为** Quota 管理者，
**我想要** 查看最近 N 天 Token、模型调用、工具调用趋势，
**以便** 识别资源消耗峰值。

### 验收标准

- 支持 `days` 参数，默认 7 天。
- 每天都有一条数据，即使当天无事件也返回 0。
- 图表展示 Token、模型调用、工具调用。
- 空数据时展示空状态。

## US-VS-03 查看模型使用分布

**作为** 模型配置者，
**我想要** 看到不同模型的 Token 和调用次数，
**以便** 判断模型路由是否符合预期。

### 验收标准

- 模型列表包含 `model_id`、展示名、Token、调用次数。
- 模型分布图根据 Token 使用量展示。
- 无 Quota 记录时展示空状态。

## US-VS-04 查看 Agent 执行表现

**作为** Agent 团队配置者，
**我想要** 查看各 Agent 的任务成功率、平均 Token、平均耗时，
**以便** 调整 Agent 配置。

### 验收标准

- 每个 Agent 返回完成任务数和失败任务数。
- 成功率按 `completed / (completed + failed)` 计算。
- 当无任务记录时使用 Agent 累计字段兜底。
- 图表可展示 Agent 成功率。

## US-VS-05 查看工具使用统计

**作为** 调试者，
**我想要** 查看工具调用量和成功率，
**以便** 判断工具层是否稳定。

### 验收标准

- 工具统计按 `tool_name` 聚合。
- 返回调用次数、成功次数、失败次数、成功率。
- Dashboard 展示工具调用柱状图。
- 无工具调用时展示空状态。

## US-VS-06 在 Quota 页面查看趋势

**作为** Quota 管理者，
**我想要** 在 Quota 页面看到资源趋势，
**以便** 不离开资源页面也能判断消耗走势。

### 验收标准

- Quota 页面嵌入趋势图或趋势卡片。
- 加载失败不影响原有 Quota 概览显示。
- 图表风格与 Dashboard 一致。

## US-VS-07 加载、错误与空状态

**作为** 任意用户，
**我想要** 在数据加载、失败、为空时看到明确反馈，
**以便** 理解系统状态。

### 验收标准

- API 加载中显示骨架或加载文案。
- API 错误显示可理解的错误提示。
- 空图表显示空状态文案。
